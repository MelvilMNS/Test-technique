# Test Technique - Restaurant

## Description

Ce projet est un test technique. Il consiste en une application de réservation de table de réstaurant.  

Le projet est structuré avec un **frontend** en Angular (avec SCSS) et d'un **backend** en Node.js / Express.

---

## Installation

Installer les dépendances pour le backend :

```
cd backend
npm install
```

Installer les dépendances pour le frontend :

```
cd frontend/restaurant
npm install
```

Le backend sera accessible à l'adresse : http://localhost:3000

Le frontend sera accessible à l'adresse : http://localhost:4200

Pour lancer le projet, ouvrir deux terminaux et exécuter **npm run start** dans chacun d'entre eux : un pour le backend ainsi qu'un pour le frontend.

## Test unitaires

Des tests unitaires sont présents côté backend et sont réalisés avec Jest. Ils peuvent être exécutés avec les commandes suivantes :
```
cd backend
npm run test
```
